## Overview

Practice-2-Digikala is a front-end project that replicates a modern e-commerce platform, emphasizing responsive design and dynamic content presentation. It leverages cutting-edge tools like Vite and Tailwind CSS to streamline development and ensure a cohesive user experience.

**Why Practice-2-Digikala?**

This project aims to provide a robust foundation for building engaging online stores with seamless styling, user authentication, and real-time product displays. The core features include:

* 🖥️ **Responsive Layout:** Ensures a visually appealing and adaptable interface across devices.
* 🎨 **Tailwind CSS & Vite Integration:** Facilitates efficient styling workflows and optimized asset handling.
* 📊 **Dynamic Content Rendering:** Loads products and articles from structured JSON data for engaging user interaction.
* 🔐 **User Registration Interface:** Supports secure onboarding via email or mobile number.
* ⚙️ **Streamlined Development:** Comes with scripts and dependencies for easy setup, build, and preview.
* 🚀 **Real-Time Updates:** Fetches and displays fresh content dynamically, enhancing user engagement.

## ⚙️ Installation & Usage

Follow these steps to set up and run the project locally 👇

### 1. Clone the repository
First, clone this project to your local machine:
```bash
git clone https://github.com/im-ho3eiin/practice-2-Digikala.git
````

### 2. Navigate to the project directory
```bash
cd practice-2-Digikala
````

### 3. Run the development server
Start the Vite dev server for live preview:
```bash
npm run dev
````
Then open the URL shown in the terminal — usually http://localhost:5173

### 4. Build for production
When you’re ready to deploy or test the optimized version:
```bash
npm run build
````
This command generates a dist/ folder with the final production files.

### 5. Preview the production build
(Optional) You can preview the built version locally:
```bash
npm run preview
````

### 6. (Optional) Run mock API with json-server
If you want to simulate API data from db.json, run:
```bash
npx json-server --watch db.json --port 3001
````
Your mock endpoints will be available at:
* http://localhost:3001/products
* http://localhost:3001/categories
